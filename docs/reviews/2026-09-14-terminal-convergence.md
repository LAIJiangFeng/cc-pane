- Windows 终止操作使用保留的 Job/进程句柄；Unix 移除与 wait 竞争的额外 reap。
- 桌面与 Web 共用序号游标；WebSocket 收发共同收尾；孤儿回收复查归属、状态和输出。

- 移除 IME 延迟预览和重复 flush 标记；图集失效按结构变化集中处理。
